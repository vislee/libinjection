# libinjection 4.0.0 全量总报告

> 3.9.2（upstream 原版，2017 年后停更）→ **4.0.0**（本 fork）
> 日期：2026-09-27
> 一句话总结：把一个只覆盖 SQLi/XSS、数据停更九年、红队召回 ~83%/~98% 的指纹引擎，
> 升级为覆盖 **11 类 OWASP 攻击**、自建+公开语料全面达标（召回 ≥95%、误报趋零）、
> 工程门禁完整（450 项单测 / 覆盖率 98% / 一键评测）的现代检测库——且全程保持

## 6. 明确边界（不做与做不了）

- OWASP A02/A04/A05 大部/A06/A07/A09：需要服务端上下文、版本清单或行为
  序列，字符串检测无信号——建议配套 SCA、安全头基线、MFA、风控、SIEM；
- CSIC other-attack 剩余 ~19%：内网主机名字典与路径字典，属枚举清单性质；
- 含引号自然语言与攻击拼接形状同构（3.8% SQLi FP 边界）：形状上不可分离，
  是无上下文检测库的理论边界；
- 对抗性逐字符变形、业务上下文（参数→SQL 位置映射）、二阶注入：超出库职责。

## 7. 结论

4.0.0 在保持 libinjection 全部原始优点（微秒级、零依赖、可解释指纹、
嵌入式友好）的前提下，把可检测攻击面从 2 类扩展到 11 类，全部自建红队
与公开语料指标达成或超过 95% 目标，并以覆盖率门禁、450 项单元测试、
双基线盲测工具链保证了后续演进的可持续性。建议在生产中作为高性能
第一层，与规则引擎/模型/风控级联使用。
